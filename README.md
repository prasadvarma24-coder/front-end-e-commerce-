# front-end-e-commerce-
A modern, responsive and interactive e-commerce using React.js, JavaScript (ES6+) and CSS3. This project provides a clean dark-themed.
"ShopEase is a responsive front-end e-commerce web application featuring product searching, category filtering, sorting, and dynamic shopping cart tracking."


🚀 Features

Responsive design for desktop, tablet, and mobile.

Product listing with images, names, and prices.

Search products by name.

Filter products by category.

Add products to the shopping cart.

Increase or decrease product quantities.

Remove products from the cart.

🛠️ Technologies Used

HTML5 – Website structure.

CSS3 – Styling, layouts, animations, and responsive design.

JavaScript (ES6) – Dynamic functionality and user interactions.
